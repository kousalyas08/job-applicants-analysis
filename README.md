Job Applicants Analysis Using Python and Pandas

📌 Project Overview

This project focuses on analyzing job applicant data using Python and Pandas. It involves data cleaning, data preprocessing, exploratory data analysis (EDA), and data visualization to understand applicant qualifications, technical skills, assessment scores, salary expectations, and hiring status.

🎯 Project Objectives

- Clean and preprocess a dataset containing job applicant information.
- Identify and handle missing values and duplicate records.
- Analyze applicant skills, education, and work experience.
- Explore patterns in aptitude, coding, interview, and communication scores.
- Understand hiring-status patterns through data analysis.
- Create visualizations to communicate useful insights.

🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

📂 Dataset Information

The dataset contains approximately 500 and more job applicant records with columns such as:

- Gender
- Education
- Experience_Years
- Skills
- Aptitude_Score
- Interview_Score
- Hiring_Status
- Age
- City
- Graduation_Year
- Certification
- Communication_Score
- Coding_Score
- Expected_Salary_LPA
- Notice_Period_Days
- Internship_Experience
- Applied_Role

🔍 Project Workflow

1. Import the required Python libraries.
2. Load the dataset using Pandas.
3. Inspect the dataset using "head()", "info()", "shape", and "describe()".
4. Identify and handle missing values.
5. Check for duplicate records and inconsistent data.
6. Perform exploratory data analysis.
7. Analyze numerical and categorical columns.
8. Create charts using Matplotlib and Seaborn.
9. Interpret the results and summarize key findings.

📊 Analysis Questions

- What is the distribution of hiring status?
- Which educational qualifications are most common?
- How does work experience vary among applicants?
- Which technical skills are most frequently listed?
- Is there a relationship between coding scores and interview scores?
- How do communication scores vary by hiring status?
- How do expected salaries differ across applied roles?
- Is internship experience associated with hiring outcomes?
